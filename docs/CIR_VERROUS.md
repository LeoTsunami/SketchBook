# Verrous R&D

Ce document liste les verrous R&D identifiés dans le projet, leurs enjeux et les solutions apportées.

Un verrou R&D doit représenter :
- Un obstacle technique significatif
- Une problématique nécessitant de la recherche
- Une incertitude sur la solution
- Un besoin d'innovation technique
- Une absence de solution standard dans l'état de l'art

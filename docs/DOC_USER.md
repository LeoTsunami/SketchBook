# Guide Utilisateur - SketchBook

## Introduction

SketchBook est une application de bureau conçue pour aider les artistes à s'entraîner au dessin d'après modèle en utilisant une bibliothèque d'images statiques. L'application simule des séances de dessin traditionnelles avec des modèles, en permettant de gérer le temps et la progression.

## Installation

1. Téléchargez la dernière version de SketchBook
2. Exécutez l'application en double-cliquant sur `main.py`

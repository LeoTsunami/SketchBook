# Configuration Cursor

Ce dossier contient les fichiers de configuration et de planification spécifiques à l'environnement de développement Cursor.

## Fichiers

```
.cursor/
├── PLANNING.md    # Architecture et vision du projet
└── TASKS.md       # Suivi des tâches et progression
```

## Utilisation

- Consultez `PLANNING.md` avant de commencer à travailler sur une nouvelle fonctionnalité
- Mettez à jour `TASKS.md` via la commande : `Update task`
